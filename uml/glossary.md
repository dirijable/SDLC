# Глоссарий BarberBook

| Термин | English | Определение | Использование |
|---|---|---|---|
| Гость | Guest | Посетитель сайта без входа, просматривающий каталог | UC-01–04 |
| Клиент | Client | Зарегистрированный пользователь, создающий и отменяющий свои записи | UC-05, 07, 08 |
| Администратор | Administrator | Сотрудник, управляющий каталогом, расписанием и записями | UC-09–13 |
| Мастер | Master | Сотрудник, оказывающий услуги по рабочему календарю | Master, WorkDay |
| Услуга | Service | Позиция каталога с названием и ценой; длительность один час | Service |
| Рабочий день | WorkDay | Датированное рабочее время либо выходной конкретного мастера | WorkDay |
| Слот | Slot | Один час мастера в конкретную дату | UC-04–06 |
| Блокировка | SlotBlock | Запрет бронирования свободного часа с причиной отсутствия | UC-12 |
| Запись | Booking | Бронирование клиентом услуги, мастера, даты и часа | UC-05, 07, 08 |
| Действующая запись | Upcoming booking | Запись со статусом UPCOMING до наступления времени услуги | Booking.status |
| Каталог | Catalog | Доступные клиенту услуги и выполняющие их мастера | UC-01, 03 |
| Напоминание | Reminder | Сообщение администратору о неполном календаре следующего месяца | UC-13 |
| Прецедент | Use case | Цель актёра, достигаемая через взаимодействие с системой | use-case.puml |
| Актёр | Actor | Внешняя роль, запускающая прецедент | use-case.puml |
| Поток событий | Flow of events | Последовательность шагов основного или альтернативного сценария | use-cases.md |
| Сторожевое условие | Guard | Условие, разрешающее переход между состояниями | state-*.puml |
| Линия жизни | Lifeline | Участник взаимодействия во времени | sequence-*.puml |
| Транзакция | Transaction | Атомарная группа операций чтения и записи БД | UC-05, UC-12 |
| ADR | Architecture Decision Record | Запись о принятом проектном решении | adr/ |
| SRS | Software Requirements Specification | Спецификация требований | srs/srs.md |
| SDD | Software Design Description | Описание архитектуры и поведения системы | sdd/BarberBook-sdd.md |
