## Описание проекта
Разработка утилиты с графическим интерфейсом для анализа и информирования пользователя о нормальном артериальном давлении. Проект реализуется на базе архитектурного паттерна MVC (Model-View-Controller) с активной моделью.

### Основной функционал:
1. **Главная форма:**
    * Кнопка «Ввести данные» для вызова формы ввода.
    * Отображение результатов: расчетного «идеального давления» (с учетом возраста и веса) и оценки текущего состояния (повышенное, пониженное, норма).
    * Сохранение и автоматическое восстановление последних введенных пользователем данных при повторном вызове формы.

2. **Диалоговое окно ввода:**
    * Запрос даты рождения (без использования стандартного встроенного элемента ввода даты).
    * Запрос массы тела (веса) и текущих показателей артериального давления.

3. **Обработка ошибок:**
    * Валидация вводимых значений с выводом сообщений об ошибках при некорректном формате данных.
